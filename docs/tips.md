## Tips and Tricks

### Create a "Temp" Packing List

Not everything belongs in a permanent list. Create a packing list called **"Temp"** (or "One-Off") for items that are specific to a single trip and don't need to persist across every trip or evolve alongside your other lists.

For example: a gift for someone you're visiting, a specific book you want to read on the plane, or a borrowed item you need to return. Add these to the Temp list, include it in your List Set, and select them for just that trip. After the trip, you can clear out the Temp list without affecting your carefully curated permanent lists.

### Set Up Cloud Backup

Before you start building your packing lists, take a moment to set up **Cloud Backup** from the home screen. Your packing lists represent real effort -- item-by-item curation built over multiple trips. A device change, factory reset, or accident shouldn't wipe that out.

Cloud Backup saves your entire database to Google Drive. Make it a habit to tap **Backup Now** after any trip where you've refined your lists. That way your latest changes are always safe.

### Use Bag Hints Liberally

If an item always goes in the same bag (toothbrush → toiletry bag, laptop → carry-on), set a bag hint on it. When you pack for a trip, the bag picker will pre-select the hinted bag, saving you a tap every time. You can set hints per-item, or assign a default bag to an entire list.

### Suggest Bags from Recent Trips

After a few trips, your actual packing decisions become a useful data source. When editing a list, use **Set Default Bag → Suggest from Recent Trips** to see how you assigned items in your last trip. You can selectively apply those suggestions to update your bag hints.

### Copy Trips for Similar Travel

If you take the same type of trip regularly (e.g., a weekly work trip or an annual family holiday), use **Copy Trip** to duplicate a past trip. Your item selections, quantities, and bag assignments carry over. Just tweak what's different and you're ready to pack.

### Use Quantities for Multiples

Long-press any item in the **Should Pack** tab to set a quantity. The dialog remembers your five most recent quantities for quick selection. This is especially useful for items like clothing where the count changes with trip length.

### Use the Notes Tab for Non-Packing Tasks

The **Notes** tab isn't just for packing notes. The to-do list is handy for pre-trip tasks like:
- Charge all devices
- Set an out-of-office reply
- Arrange pet care
- Print boarding passes
- Take out the rubbish

These to-dos can be copied along with a trip, so recurring pre-trip tasks don't need to be re-entered.

### Search to Find Items Fast

Both the **Packing Lists** screen and the **Trip Detail** screen have a search function. In a trip, search results show the item's category, bag assignment (with color chip), and current packing status -- making it easy to find and check on any item without scrolling through lists.

### Use Clear Repack for Multi-Stop Trips

If your trip involves multiple stops (e.g., hotel A → hotel B), use the **Clear Repack** menu action after repacking at your first stop. This resets all repacked items back to packed status so you can repack again at the next stop.

### Prioritise Your Lists and Items

Both lists and items have a priority (weight) field. Higher-priority entries appear first. Put your most important or most-used lists and items at the top so they're always easy to find.
