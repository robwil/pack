## The Packing Workflow

Pack is built around a clear, repeatable workflow. Here's how all the pieces fit together.

### 1. One-Time Setup

These steps only need to be done once (or whenever your gear changes):

1. **Create your bags** -- Go to **Bags** and add entries for each piece of luggage you own. Pick a color for each so they're easy to distinguish. Examples: "Carry-on" (blue), "Checked Bag" (red), "Daypack" (green).

2. **Create your packing lists** -- Go to **Packing Lists** and create a list for each category of items. Add all the items you might ever bring. You don't have to bring everything on every trip -- you'll choose per-trip later.

3. **Assign bag hints** -- For items that always go in the same bag, assign a bag hint. You can do this per-item, or set a default bag for an entire list (e.g., all toiletries go in the carry-on).

4. **Create list sets** -- Go to **List Sets** and bundle your lists into trip types. You might only need one or two sets to cover all your travel.

### 2. Before Each Trip

1. **Create a trip** -- Go to **Trips**, tap add, name your trip, and select the appropriate List Set.

2. **Should Pack tab** -- Go through each list and select the items you want to bring. Long-press to set quantities where needed (e.g., 5x underwear, 3x T-shirts).

3. **Add notes and to-dos** -- Switch to the **Notes** tab to jot down anything else: flight times, hotel details, things to buy before you leave.

### 3. Packing Day

1. **Pack tab** -- As you physically pack each item, tap it to check it off. If you have bags enabled, you'll be prompted to select which bag it goes into. The app remembers your usual choices.

2. **Check bag contents** -- Tap any bag in the legend to see everything assigned to it. This is especially useful when deciding if a bag is too full.

### 4. Coming Home

1. **Repack tab** -- As you pack up to head home, check off each item. This ensures nothing gets left behind at your hotel or destination.

2. **Copy for next time** -- If you'll take a similar trip again, use **Copy Trip** to duplicate it. Your item selections, quantities, bag assignments, and optionally notes and to-dos are all preserved as a starting point.

```
Define Lists & Bags (once)
        │
        ▼
  Create List Sets (once)
        │
        ▼
  ┌─ Create Trip ──────────────────────┐
  │                                    │
  │  Should Pack → Pack → Repack       │
  │       │          │        │        │
  │    select     check off  check off │
  │    items      + assign   for home  │
  │    + qty      bags                 │
  │                                    │
  │  Notes & To-dos (anytime)          │
  │                                    │
  └────────────── Copy Trip ───────────┘
                     │
                     ▼
              Next trip starts
              pre-populated
```
